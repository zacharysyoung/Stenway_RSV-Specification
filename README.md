# JSON Typed Table

- Use JSON's string, number, boolean, and null values for field
- Delimit fields with a tab within a record, delimit records with a newline
- Require a header record of just strings

```none
"Name"	"Age"	"Salary"	"Retiring"	"Notes"
"Foo"	1	2.1	false	""
"Bar"	4	6.75	true	null
"Baz"	2	2.5	false	"wants to be promoted to \"Boss\", and\nget a raise"
```
